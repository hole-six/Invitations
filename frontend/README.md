# Thiệp Cưới Online - Wedding Invites

Ứng dụng thiết kế thiệp cưới online cao cấp được xây dựng bằng React + Vite + TailwindCSS.

## 🚀 Tính năng

- ✨ Trang chủ với hero section đẹp mắt
- 🎨 Bộ sưu tập mẫu thiệp với hiệu ứng 3D
- ✏️ Trình chỉnh sửa thiệp trực quan
- 📊 Quản lý dự án thiết kế
- 💰 Trang bảng giá với 3 gói dịch vụ
- 📞 Trang liên hệ và hỗ trợ
- 🌙 Hỗ trợ Dark Mode
- 📱 Responsive trên mọi thiết bị

## 🛠️ Công nghệ sử dụng

- **React 18** - Thư viện UI
- **Vite** - Build tool siêu nhanh
- **React Router** - Điều hướng trang
- **TailwindCSS** - CSS Framework
- **Material Symbols** - Icon library

## 📦 Cài đặt

```bash
# Cài đặt dependencies
npm install

# Chạy development server
npm run dev

# Build production
npm run build

# Preview production build
npm run preview
```
